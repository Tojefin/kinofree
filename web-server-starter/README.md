# Web Server Starter

Набор скриптов для быстрого запуска локального веб-сервера с актуальной версией сайта.

Поддерживаются **Windows, macOS и Linux**.

### Как это работает

- Использует Python 3 для запуска веб-сервера.
- На Windows автоматически загружает портативную версию Python — установка не требуется.
- Автоматически загружает актуальную сборку сайта из GitHub Pages.
- Генерирует Python-скрипт для запуска локального веб-сервера.

**Минимум настроек — достаточно запустить скрипт для подготовки и запуска сервера.**
